## Detailed Description

```
ReCalibri restores accessible typography on websites by replacing Times New Roman with fonts designed for readability and accessibility.

WHY RECALIBRI EXISTS

In December 2025, the U.S. State Department reversed a 2023 accessibility directive, switching back from Calibri to Times New Roman. The original change was made to "mitigate accessibility issues for individuals with disabilities."

Times New Roman's decorative serifs create barriers for:
• People with visual disabilities
• People with dyslexia
• Anyone using screen readers
• Those with reading difficulties

ReCalibri restores the accessible typography that was removed.

KEY FEATURES

Three Accessible Font Options:
• Calibri - Clean, modern sans-serif recommended by accessibility experts
• Open Sans - Highly legible, optimized for screen reading
• OpenDyslexic - Specially designed for people with dyslexia

Flexible Scope:
• .gov sites only (default) - Target government websites
• All websites - Apply globally across the web

Accessibility-First Design:
• Light/Dark mode toggle for visual comfort
• Adjustable font sizes in popup
• Keyboard navigation support
• Screen reader compatible
• WCAG AA compliant contrast ratios

Automatic & Real-Time:
• Works on static and dynamically loaded content
• Real-time monitoring for new content
• No page reload required
• Minimal performance impact

PERFECT FOR

• People with visual disabilities seeking better readability
• People with dyslexia who need specialized fonts
• Government employees accessing .gov websites
• Accessibility advocates supporting inclusive design
• Anyone who values readable, accessible typography

THE SCIENCE

Research shows that sans-serif fonts:
• Improve reading speed for people with dyslexia
• Are easier to read for people with low vision
• Render better on digital screens
• Are recommended by WCAG and Section 508 standards
• Provide better text-to-speech compatibility

HOW IT WORKS

1. Click the ReCalibri icon in your toolbar
2. Choose your scope (.gov only or all websites)
3. Select your preferred accessible font
4. Customize light/dark mode and font size
5. Browse normally - fonts are automatically replaced

PRIVACY & SECURITY

• No data collection or tracking
• No external server communication (except CDN for OpenDyslexic)
• Settings stored locally only
• Open source and auditable
• No ads, no tracking, no nonsense

TECHNICAL DETAILS

• Built with Manifest V3 (latest standard)
• Minimal permissions (Storage, Active Tab)
• Efficient font detection and replacement
• MIT License - free and open source

SUPPORT & CREDITS

Created by Luke Steuber (dr.eamer.dev)
Licensed under MIT License
Free and open source

Accessibility isn't political—it's essential.

Restore accessible typography today with ReCalibri.
```

## Single Purpose Statement (for Privacy Tab)


---

## Permissions Justification (for Privacy Tab)

**Storage Permission:**
```
Required to save user preferences including:
- Scope setting (gov-only or global mode)
- Font selection (Calibri, Open Sans, or OpenDyslexic)
- Theme preference (light or dark mode)
- Font size preference
All settings are stored locally and never transmitted to external servers.
```

**Active Tab Permission:**
```
Required to detect the current tab's URL to determine if it's a .gov domain when in gov-only mode. No browsing history is collected or stored.
```

**Host Permissions (<all_urls>):**
```
Required to inject content scripts that detect and replace Times New Roman font on web pages according to user preferences. The extension only modifies font styling and does not access, collect, or transmit any page content or user data.
```

---

## Data Usage Declaration (for Privacy Tab)
```
This extension does NOT collect, transmit, or sell any user data.

The extension only stores locally:
- User preference for scope (gov-only or global mode)
- User preference for font (Calibri, Open Sans, or OpenDyslexic)
- User preference for theme (light or dark mode)
- User preference for font size

This data is:
- Stored locally in Chrome's sync storage
- Never transmitted to external servers
- Never shared with third parties
- Only used to control extension behavior

External Resources:
- OpenDyslexic font is loaded from jsdelivr.net CDN when selected
- No tracking, analytics, or data collection occurs
```

## Test Instructions (Optional)

```
TESTING INSTRUCTIONS

Basic Functionality:
1. Install the extension
2. Click the ReCalibri icon in the Chrome toolbar
3. Test .gov sites only mode:
   - Select ".gov sites only"
   - Select "Calibri" font
   - Visit https://www.usa.gov or https://www.whitehouse.gov
   - Verify that Times New Roman fonts are changed to Calibri
   - Visit a non-.gov site and verify fonts are NOT changed

4. Test All websites mode:
   - Select "All websites"
   - Visit any website with Times New Roman font
   - Verify that fonts are changed to Calibri

Font Options:
5. Test Open Sans:
   - Select "Open Sans" font
   - Reload a page and verify the font changes

6. Test OpenDyslexic:
   - Select "OpenDyslexic" font
   - Reload a page and verify the specialized dyslexia font is applied

Accessibility Features:
7. Test Dark Mode:
   - Click the moon icon in the popup
   - Verify the popup switches to dark theme

8. Test Font Size:
   - Click the "A+" button multiple times
   - Verify the popup text size increases

9. Test Keyboard Navigation:
   - Use Tab key to navigate through popup options
   - Verify all controls are accessible via keyboard

No special credentials or setup required.
```
