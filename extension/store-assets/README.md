This folder contains all the promotional images and screenshots needed for the Chrome Web Store listing.

2. **promo-marquee-1400x560.png** (OPTIONAL - Recommended)

## Upload Instructions

When filling out the Chrome Web Store listing:

1. **Store Listing Tab → Promotional Images**
   - Upload `promo-small-440x280.png` (required)
   - Upload `promo-marquee-1400x560.png` (optional but recommended)

2. **Store Listing Tab → Screenshots**
   - Upload all 3 screenshots
   - Arrange them in order: popup → before/after → gov site
   - You can upload up to 5 total (currently have 3)
